# 越南跨年之旅（Family trip）

2026/12/31（四）– 2027/01/03（日）胡志明市 4 天 3 夜的團體行程網站。
加到手機主畫面後可以當 App 用，出國沒網路也能看行程、會話卡和緊急電話。

- 網址：<https://hagan-huang.github.io/FamilyTrip/>
- 目前版本：v1.1.0（2026-11-17）

---

## 一、給團員的使用說明

### 1. 加到主畫面

| 手機 | 做法 |
|---|---|
| iPhone | 用 **Safari** 開網址 → 下方「分享」按鈕 → **加入主畫面** |
| Android | 用 **Chrome** 開網址 → 右上角 ⋮ → **加到主畫面**（或「安裝應用程式」） |

主畫面會出現「Family trip」圖示。**出發前請至少在有網路的地方打開一次**，之後離線也能用。

### 2. 登入

封面按「點我進入」後要登入：

- **暱稱**：自己取，之後都用同一個
- **個人密碼**：自己設，至少 4 個字（錯 8 次會鎖 15 分鐘）
- **團體密碼**：問主辦人

換手機時用同一組暱稱和密碼登入，記帳、打勾、登記的航班都會回來。

### 3. 五個分頁

| 分頁 | 內容 |
|---|---|
| 主頁 | 出發倒數、下一站、工具箱、天氣、匯率、出發前進度、我的花費、畫面風格 |
| 航班 | 去回程車票卡；按「登記：我搭這組航班」 |
| 行程 | 每天的時間軸。左右滑動換天；右上角可以把某一天分享到 LINE |
| 準備 | 待辦、待買清單（可自己新增刪除）、住宿資訊、給司機看的地址 |
| 記帳 | 記一筆（個人／分帳）、我的帳、團體分帳與結算建議 |

**旅行當天**打開行程，會自動標出「進行中」「下一個」，有關門時間的景點會倒數，剩 45 分鐘內變色。點景點名稱直接開 Google 地圖導航。

### 4. 工具箱（沒網路也能用）

- **回住宿**：一按開 Google 地圖導航回今晚的飯店（這個需要網路）
- **給司機看**：今晚住宿的越南文地址，大字顯示
- **會話卡**：點一句越南語會放大成白底大字，拿給店員看
- **緊急求助**：電話點了直接撥；下面可以填自己的保險、信用卡掛失電話（只存在自己手機）
- **旅遊須知**：簽證、換錢、交通、退稅等

### 5. 常見問題

- **畫面沒更新？** 把 App 整個關掉再打開，重複一兩次。
- **沒網路時記帳？** 可以。先存在手機，有網路後自動上傳。
- **忘記個人密碼？** 請主辦人到試算表「成員」分頁把你那一列刪掉，再用同一個暱稱重新加入（雲端的個人資料還在）。

## 二、給主辦人的說明

### A. 開 GitHub Pages（只要做一次）

1. 到 repo 頁面 → **Settings** → 左邊 **Pages**
2. **Source** 選 `Deploy from a branch`
3. **Branch** 選 `main`、資料夾選 `/ (root)` → **Save**
4. 等 1–2 分鐘，網址就是 <https://hagan-huang.github.io/FamilyTrip/>

### B. 建立 Google 試算表後端（只要做一次）

還沒做這一步之前，網站是「單機模式」：可以看行程、用工具箱、記自己的帳，但不能多人同步。

1. **建試算表**：瀏覽器開 <https://sheets.new>，左上角把檔名改成「越南跨年之旅」。
2. **開 Apps Script**：上方選單 **擴充功能 → Apps Script**，會開一個新分頁。
3. **貼程式**：把編輯區原本的 `function myFunction() {…}` 全部刪掉，貼上本 repo [`apps-script/Code.gs`](apps-script/Code.gs) 的全部內容。
4. **改密碼**：第 7 行 `const GROUP_PASSWORD = '請改成你們的團體密碼';`，把引號裡的字換成你們的團體密碼（不要太短）。按上方的磁碟圖示儲存。
5. **建立分頁並授權**：上方函式下拉選單選 `setup` → 按 **執行**。
   第一次會跳出授權：**審查權限** → 選你的 Google 帳號 → 看到「Google 尚未驗證這個應用程式」時按 **進階** → **前往「…」（不安全）** → **允許**。
   （這是因為程式是你自己寫的、沒送 Google 審核，屬正常現象。）
   回到試算表會看到六個分頁：`成員`、`分帳紀錄`、`個人資料`、`每日`、`行程`、`行程備份`。
6. **部署**：右上角 **部署 → 新增部署作業** → 左邊齒輪選 **網頁應用程式** →
   - 執行身分：**我**
   - 誰可以存取：**所有人**

   按 **部署**，複製「網頁應用程式」網址（長得像 `https://script.google.com/macros/s/…/exec`）。
7. **把網址交給網站**：把網址傳給 Claude，或自己貼到 [`data.js`](data.js) 最上面的 `API_URL = ''` 引號裡。

接上之後，第一個登入的人會把內建行程自動寫進試算表（畫面會出現「已把行程寫進試算表」），**之後一律以試算表為準，網站不會再覆蓋**。

> ⚠️ **以後只要 `Code.gs` 有改**：要把新內容**重新貼上**、**填回第 7 行的團體密碼**，然後 **部署 → 管理部署作業 → 鉛筆 → 版本選「新版本」→ 部署**（網址不會變）。

### C. 試算表怎麼填

主辦人直接改試算表，團員重新整理網頁就更新。

**「每日」分頁**（一天一列）

| 日期 | 標題 | 住宿 | 人數 |
|---|---|---|---|
| 12/31 | 抵達西貢・跨年倒數 | 飯店名稱 | 4 |

**「行程」分頁**（一列一個項目，順序不拘，網頁會照時間排）

| 欄位 | 怎麼填 |
|---|---|
| 日期 | `12/31`、`1/1` 這種寫法，要跟「每日」一致 |
| 時間 | 24 小時制，例如 `09:30` |
| 類型 | 下拉：景點／餐廳／交通／備註 |
| 內容 | 顯示的文字。寫到「集合」或「會合」會特別標出來 |
| 交通 | 下拉：步行／Grab／計程車／包車／地鐵／公車／船／飛機 |
| 地點 | Google 地圖找得到的名稱，越南文最準（例如 `Dinh Độc Lập`） |
| 關門時間 | 例如 `17:30`，旅行當天會倒數 |
| 組別 | 全員參加留空 |
| 人數 | 只有部分人參加時填，例如 `2` |
| 待定 | 還沒確定就打勾 |
| 備註 | 小字說明 |

注意：開頭不要用 `=`、`+`、`-`、`@`。日期和時間欄已設成純文字，不會被自動轉格式。

**整天重排**：在 `data.js` 的 `ITIN_PATCHES` 加一筆（`id` 不能重複），網站會把那一天整天換掉，換之前自動備份到「行程備份」。

### D. 住宿訂好之後

把飯店資料填進 `data.js` 的 `HOTELS`（檔案裡有範例），同時在試算表「每日」的住宿欄填飯店名稱。
`addrLocal` 請填越南文地址，「給司機看」「回住宿」都靠它。

### E. 圖片

封面與分頁橫幅的 Gemini 提示詞在 [`docs/圖片提示詞.md`](docs/圖片提示詞.md)。
畫好後壓縮（封面建議寬 1080、JPG 品質 80、300 KB 以內），放進 `images/`，再改 `data.js` 的 `IMG`。

### F. 改版時要一起改的版本號

| 檔案 | 位置 |
|---|---|
| `index.html` | `window.APP_VER`、`window.APP_DATE`，以及所有 `?v=` |
| `sw.js` | `VER`，以及 `CORE` 裡的 `?v=` |
| `manifest.webmanifest` | 圖示的 `?v=` |

漏改的話手機會讀到舊快取。改完後請團員把 App 關掉重開一兩次。

### G. 資安提醒

- **這個 repo 是公開的**。航班號和（之後填的）住宿地址任何人都看得到；**不要放訂位代號、護照號碼、個人電話**。
- 團體密碼只存在 Apps Script 裡，GitHub 上永遠是「請改成你們的團體密碼」。
- 個人密碼在試算表裡是加鹽雜湊，看不到原文。
- 分帳紀錄要登入後才讀得到；行程不含個人資料，拿到網址就能看。
- **團體密碼外流時**：改 Apps Script 第 7 行 → 重新部署新版本。所有人會被登出，用新密碼重新登入即可（資料都還在）。
- 請幫 GitHub 和 Google 帳號開**雙重驗證**。

### I. 檔案

```
index.html             版面與樣式
data.js                資料（航班、住宿、待辦、待買、會話卡、緊急電話、須知）← 改資料只改這裡
app.js                 程式
sw.js                  離線快取
manifest.webmanifest   加到主畫面的設定
apps-script/Code.gs    Google 試算表後端
images/                封面、圖示
docs/                  規格、圖片提示詞
```

每天行程卡右邊的插圖會依標題自動挑（煙火、教堂、市場、椰子樹…），想指定就改 `data.js` 的 `DAY_ART`。
手機若開了「減少動態效果」，所有動畫會自動關閉，插圖仍會顯示。

測試小技巧：網址後面加 `?now=2027-01-01T10:20` 可以模擬「旅行中某一天的某個時間」（越南時間）。
