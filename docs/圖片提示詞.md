# Gemini 圖片提示詞（預設風格：漆藝夜色）

共同原則：近黑底、米白線條、**只有朱漆紅一個強調色**，像越南磨漆畫（sơn mài）。不要文字、不要人物。

## 封面（直式 9:16）

```
直式 9:16 插畫，越南磨漆畫（sơn mài）風格。近黑色的漆面背景，帶細微的蛋殼鑲嵌質感。
畫面上方三分之二：夜晚的西貢天際線剪影（法式鐘樓市政廳、雙塔教堂、遠方的現代高樓），
後方一輪巨大的朱漆紅圓月，天空有幾朵細線條的跨年煙火，河面有紅色倒影。
配色只用三種：近黑、米白細線、朱漆紅，不要其他顏色。
畫面下方三分之一保持暗而乾淨的純黑漸層，不要任何物件（之後要放標題）。
構圖簡潔、大量留白、精品感。不要任何文字、字母、招牌、浮水印，不要人物。
```

## 分頁橫幅（橫式 3:1，可選）

五張用同一段，只換【主體】：

```
橫式 3:1 插畫，越南磨漆畫（sơn mài）風格，近黑色漆面背景，米白細線條，
只有朱漆紅一個強調色。主體是【主體】，置於畫面右側三分之一，
左側三分之二保持暗而乾淨（之後要放標題）。構圖簡潔、留白多、精品感。
不要任何文字、字母、浮水印，不要人物。
```

| 分頁 | 【主體】 |
|---|---|
| 主頁 | 一頂越南斗笠與一朵蓮花 |
| 航班 | 夜晚的機場跑道與起飛的客機剪影 |
| 行程 | 西貢市政廳鐘樓與一台偉士牌機車 |
| 準備 | 打開的行李箱與一張車票 |
| 記帳 | 幾枚硬幣與一個皮夾 |

## 放進網站

1. 壓縮：封面寬 1080px、JPG 品質約 80（300 KB 以內）；橫幅寬 1200px（150 KB 以內）；圖示輸出 512、192、180 三種 PNG。
2. 檔案放進 `images/`。
3. 改 `data.js`：`const IMG = { cover: 'images/cover.jpg', banners: { home: 'images/b-home.jpg', … } };`
4. 圖示直接覆蓋 `images/icon-512.png`、`icon-192.png`、`apple-touch-icon.png`。
5. 記得改版本號（見 README「改版時要一起改的版本號」），`sw.js` 的 `CORE` 裡封面檔名也要跟著改。

橫幅只有切到那個分頁才會下載，不影響第一次開啟的速度。
