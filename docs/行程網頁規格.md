## 架構

- 純靜態、無建置工具：`index.html`（版面樣式）、`data.js`（資料）、`app.js`（程式）、`sw.js`、`manifest.webmanifest`
- 後端：Google 試算表＋Apps Script（`apps-script/Code.gs`）
  - 分頁：成員、分帳紀錄、個人資料、每日、行程、行程備份
  - 讀行程不用密碼（GET）；其他都用 POST
  - 登入：暱稱＋個人密碼＋團體密碼 → 伺服器發登入憑證；之後的讀寫用憑證（憑證與團體密碼綁定，改團體密碼就全部失效）
  - 個人密碼加鹽 SHA-256；錯 8 次鎖 15 分鐘
  - 寫入用 LockService；個人資料每格 45,000 字分段
  - 文字開頭 `= + - @` 一律拒絕
- 版本號：`index.html` 的 `APP_VER`／`?v=`、`sw.js` 的 `VER`／`CORE`、`manifest` 的 `?v=` 同步更新

## 資料流

- 行程：試算表為準 → 手機快取（離線顯示上次的）→ 沒接試算表時用 `data.js`
- 第一次登入且試算表沒有行程 → 自動寫入 `data.js` 的行程，之後不覆蓋
- `ITIN_PATCHES`：整天覆寫，每個 id 只套一次，先備份
- 個人資料（記帳、勾選、清單增減、航班登記、預算、自訂匯率）：先存手機，上線自動上傳；換手機登入取回
- 分帳：存試算表；離線時排隊，上線補傳（用 id 防重複）
- 保險、信用卡掛失電話：只存手機，不上傳

## 五個分頁

1. 主頁：日期與倒數、下一站與當日摘要、工具箱、天氣（Open-Meteo）、匯率（open.er-api.com）、出發前進度、我的花費、風格切換、版本
2. 航班：車票卡、登記航班
3. 行程：日期軸＋吉祥物、每日卡、時間軸、旅行當天模式、分享（`#d=M/D`）、左右滑動
4. 準備：待辦、待買（可增刪、印章）、給司機看、住宿卡
5. 記帳：記一筆、我的帳、團體分帳（最少轉帳結算）

工具箱：回住宿、給司機看、會話卡（26 句、Wake Lock）、緊急求助、旅遊須知

## v1.2.0 全面優化

**資安**
- CSP（`script-src 'self'`，沒有行內程式；`connect-src` 白名單；`form-action 'none'`；`object-src 'none'`）
- 版本號改放 `<html data-ver data-date>`；字型改由程式載入（為了 CSP）
- 防框架嵌入；外部 API 資料一律轉數字
- 後端：團體密碼節流（CacheService，10 分鐘 20 次）、成員上限 30、登出撤銷憑證、個人資料 JSON 驗證、覆寫筆數上限

**功能**
- 試算表新增「住宿」「公告」分頁（免登入可讀）；住宿不必再改 data.js
- 行程：重新整理鈕＋資料來源／更新時間、有變動跳提示、日期軸置頂、當天自動捲到進行中、每日卡顯示待定數
- 主頁：公告卡、加到主畫面提示、下一站倒數與導航鈕、越南／台灣雙時鐘、鈔票對照、同步狀態、設定卡（大字模式、分享網站、立即同步）
- 記帳：可選日期、越南盾小金額防呆、「你要給誰／誰要給你」
- 工具：會話卡聽發音、複製地址、我現在的位置（定位）、航班即時動態連結
- Android 返回鍵先關面板；manifest 捷徑（`#p=itin` 等）；404 頁

**介面**
- 漆藝夜色：頂部暖色光暈、卡片細微光澤；底部選單與置頂日期軸改毛玻璃
- 工具箱圖示加底塊；刪除鈕點擊範圍加大；鍵盤焦點框
- 瀏海區加一條底（淺色風格用深色，狀態列文字才看得到）
- 大字模式用 `zoom:1.14`

全部是程式內建的細線 SVG，跟著風格變色，不用另外下載，離線可用。支援 `prefers-reduced-motion`（動畫全關、插圖保留）。

| 分頁標題 | 主頁蓮花、航班飛機沿航線飛、行程市政廳、準備行李箱與斗笠、記帳硬幣；進頁時一筆一筆畫出來 |
