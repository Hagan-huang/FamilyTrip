## 架構

- 純靜態、無建置工具：`index.html`（版面樣式）、`data.js`（資料）、`app.js`（程式）、`sw.js`、`manifest.webmanifest`
- 後端：Google 試算表＋Apps Script（`apps-script/Code.gs`）
  - 分頁：成員、分帳紀錄、個人資料、每日、行程、行程備份
  - 讀行程不用密碼（GET）；其他都用 POST
  - 登入：暱稱＋個人密碼＋團體密碼 → 伺服器發登入憑證；之後的讀寫用憑證（憑證與團體密碼綁定，改團體密碼就全部失效）
  - 個人密碼加鹽 SHA-256；錯 8 次鎖 15 分鐘
  - 寫入用 LockService；個人資料每格 45,000 字分段
  - 文字開頭 `= + - @` 一律拒絕
- 版本號：`index.html` 的 `APP_VER`／`?v=`、`sw.js` 的 `VER`／`CORE`、`manifest` 的 `?v=` 同步更新

## 資料流

- 行程：試算表為準 → 手機快取（離線顯示上次的）→ 沒接試算表時用 `data.js`
- 第一次登入且試算表沒有行程 → 自動寫入 `data.js` 的行程，之後不覆蓋
- `ITIN_PATCHES`：整天覆寫，每個 id 只套一次，先備份
- 個人資料（記帳、勾選、清單增減、航班登記、預算、自訂匯率）：先存手機，上線自動上傳；換手機登入取回
- 分帳：存試算表；離線時排隊，上線補傳（用 id 防重複）
- 保險、信用卡掛失電話：只存手機，不上傳

## 五個分頁

1. 主頁：日期與倒數、下一站與當日摘要、工具箱、天氣（Open-Meteo）、匯率（open.er-api.com）、出發前進度、我的花費、風格切換、版本
2. 航班：車票卡、登記航班
3. 行程：日期軸＋吉祥物、每日卡、時間軸、旅行當天模式、分享（`#d=M/D`）、左右滑動
4. 準備：待辦、待買（可增刪、印章）、給司機看、住宿卡
5. 記帳：記一筆、我的帳、團體分帳（最少轉帳結算）

工具箱：回住宿、給司機看、會話卡（26 句、Wake Lock）、緊急求助、旅遊須知
